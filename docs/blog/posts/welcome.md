# 欢迎来到 Lei-Lab 知识平台 🎉

经过一段时间的建设，**Lei-Lab 知识共享平台**正式上线！

本平台旨在为课题组成员提供一个统一的知识管理与分享空间，涵盖以下几个核心模块：

<!-- more -->

## 平台模块介绍

### 📚 课程
系统整理课题组常用的统计学、线性代数、机器学习等基础课程，配有公式推导与代码示例，方便成员自学与复习。

### 🔬 文献抄读
定期分享课题组精读的最新文献，包含研究背景、方法解析、结果点评与个人思考，帮助成员快速掌握领域前沿。

### 💻 代码库
收录课题组自研工具（如 `histox`）的 API 文档与使用教程，降低上手门槛。

### 📝 博客
记录课题组的研究动态、技术心得与学习笔记，欢迎成员投稿。

---

## 如何参与贡献？

1. 联系管理员获取平台编辑权限
2. 访问右上角 **✏️ 管理** 入口，即可在线编辑内容
3. 也可以直接向 GitHub 仓库提交 Pull Request

> 知识因分享而增值，欢迎每一位成员积极贡献！ 🚀
