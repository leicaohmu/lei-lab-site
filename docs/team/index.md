# 认识我们

## 课题组简介

Lei-Lab 专注于计算病理学与医学人工智能研究，致力于将深度学习技术应用于数字病理图像分析。

---

## 研究方向

- 🔬 **数字病理学** — 全切片图像（WSI）分析
- 🤖 **多示例学习（MIL）** — 弱监督病理分类
- 🧬 **自监督学习（SSL）** — 病理基础模型预训练
- 📊 **不确定性量化** — 模型置信度评估
- 🎨 **可解释性 AI** — 热力图与显著性分析
